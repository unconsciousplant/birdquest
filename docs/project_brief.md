# BirdQuest

## Purpose
A university-project prototype helping Hong Kong birdwatchers
plan trips, identify birds from photographs, and learn about species.

## Main features

### Trip planning
Inputs: location, date, time range, optional target species.
Outputs: ranked species, suggested observation spots, and
clearly explained model scores or confidence indicators.

### Bird identification
Upload and preview a bird photograph.
Show ranked species matches.
Later connect our Teachable Machine image classifier.

### Bird assistant
Answer questions about species, habitats, behaviour,
seasonal occurrence, and conservation.
Allow questions about a species selected on another screen.

## First milestone
A working, mobile-responsive interface with clearly labelled
mock data and replaceable services.

## Constraints
- No login, payments, or database initially.
- No invented model accuracy or performance claims.
- Do not present mock outputs as real predictions.
- No API keys or secrets in frontend code.
- Do not publish personal information or student IDs.
